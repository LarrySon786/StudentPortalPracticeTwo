Authentication + authorization
- Need builder.Services.AddCascadingAuthenticationState()
- Need builder.Services.AddAuthorization()
- Need builder.Services.AddIdentity<ApplicationUser, IdentityRole>()
    .AddEntityFrameworkStores<ApplicationDbContext>()
    .AddDefaultTokenProviders();
- Need builder.Services.ConfigureApplicationCookie(options => // Cookie configurations
{
    options.Cookie.Name = "StudentPortal.Identity";
    options.Cookie.HttpOnly = true;
    options.Cookie.SameSite = SameSiteMode.Lax;
    options.LoginPath = "/login";
    options.ExpireTimeSpan = TimeSpan.FromMinutes(30);
    options.SlidingExpiration = true;
});
- Need the app.UseAuthentication() + app.UseAuthorization()
- Login and logout use <form> NOT <EditForm>
- They must be done through HTTP requests through an app.map() method
- The submission happens from <form method="post" action="/account/login" >
- Make sure cookie is being created. See program.cs for details of route request and cookie creation.
- Roles are assigned at user creation.
- Cookie expiration, persistence, and other settings are set before app.build().
