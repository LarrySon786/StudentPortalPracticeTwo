**Student Portal Project | CSU University**
This project was made by a computer science student learning and improving his ability to build in the .NET runtime. 

**Scope**
The project's scope includes creating a fully operation university app for school management. Students can apply to the school, receive acceptance or denial emails, set up an account, login, register for courses, manage existing classes, view completed classes, monitor degree progress, submit student support tickets, and more. The project also includes a faculty management portal where instructors can create class sessions, enable them for student registration, begin classes at the start of each term, create student assignments, grade student assignments, and submit grades at the end of the term. There is an admin management portal that allows admins to create degrees, courses, and class sessions. Admins also can approve/deny students who applied to the school, respond to student support ticket requests, create new faculty members, view student information on a dashboard, create and manage terms, and more.

Technologies Included
* This project uses C# in an ASP.NET runtime enviroment.
* The chosen gramework is **Blazor**
* A postgres Database is employeed for data storage.
* Identity Core is used for Authentication and Authorization between the roles of "Admin", "Faculty", and "Student" within the same system.
* Microsoft Entity Framework Core is used for designing the database and performing CRUD operations
* SendGrid is used for Email Services
